# Changelog

All notable changes to Stux.Design Status (status.stux.design) are documented here. This
project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## v1.0.2

### Changed

- The logos and icons in the Markdown docs (README and the like) follow GitHub's light or dark theme, using each brand's `logo-light`/`logo-dark` and `icon-light`/`icon-dark` files

## v1.0.1

## v1.0.0

### Added

- Stux.Design's status page at [status.stux.design](https://status.stux.design), built with [GitHup](https://githup.stux.group) in Stux.Design magenta (`#e71081`): the Stux.Design website and media CDN are checked every 5 minutes, and the Services site and page templates are listed "On the drawing board" until they serve
- The Boring Legal Stuff hub, 404 page and sitemap, generated by GitHup from the `legal:` block in `.githup.yml`
- The live status table in this README and a status badge, both read from `data/summary.json`
